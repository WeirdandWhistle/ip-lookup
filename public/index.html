Endpoints

/ip gives you you ip and location.
/ip/{i.p.v.4} gives you the location of the ipv4.

Data structures

every thing is surrounded by:

{
    ok: boolean,
    error?: string,
    data?: object,
}

ok=true defines error

ok=false defines data


all /ip endpoints have data:

{
    ip: string,
    country: string,
    state: string,
    city: string,
    latitude: float,
    longitude: float,
}

Source code can be found in the github repo or in the /src dir

Privacy

ip.whynotjava.net collects basic logging information. This includes: ip-address, User-Agent, response time, response code, and referer header. This is shared with no one.
